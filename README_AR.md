## نبذة عن المشروع وأهدافه التعليمية

في مجالات الهندسة والعلوم التطبيقية، تواجهنا دائماً معادلات رياضية معقدة يتعذر حلها بالصيغ التحليلية المغلقة المباشرة، أو أنظمة خطية ضخمة تتطلب حلولاً تكرارية تقريبية، أو بيانات تجريبية تحتاج لمواءمة منحنى رياضي يصف سلوكها الفيزيائي بدقة.

يهدف هذا البرنامج إلى تقديم أداة عملية وممتعة لطلاب كليات الهندسة والعلوم في مقرر **التحليل العددي (Math 3)** من خلال:
1. توفير خطوات الحل التكرارية بدقة متناهية وجداول مفصلة لحساب مقدار الخطأ (Error Residuals).
2. إمكانية كتابة المعادلات بالصيغة الرياضية الطبيعية للإنسان (مثل `2x`, `x^3 - x - 2`, `e^x - 3x`, `cos(x)`).
3. إمكانية فحص السيادة القطرية للمصفوفات وتعديل ترتيب الصفوف تلقائياً لضمان تقارب الحل وتفادي التباعد.
4. حساب معامل التحديد $R^2$ والخطأ المعياري $S_{y/x}$ ورسم منحنيات الانحدار مع نقاط البيانات لحظياً.

## الشرح الرياضي التفصيلي للخوارزميات

### 1. طرق إيجاد جذور المعادلات غير الخطية (Root Finding)

تبحث هذه الطرق عن القيمة $x^*$ التي تجعل قيمة الدالة منعدمة: $f(x^*) = 0$.

#### طريقة تنصيف الفترات (Bisection Method)
- **الأساس النظري**: تستند إلى مبرهنة القيمة الوسطية (Bolzano's Theorem). إذا كانت الدالة $f(x)$ متصلة على الفترة $[a, b]$ وتحقق شرط اختلاف الإشارة $f(a) \cdot f(b) < 0$، فهذا يضمن وجود جذر واحد على الأقل في الفترة.
- **قانون التكرار**: يتم تنصيف الفترة تدريجياً:
  $$c = \frac{a + b}{2}$$
- **تحديث الفترة**:
  - إذا كان $f(a) \cdot f(c) < 0$ فإن الجذر في النصف الأول $\implies b = c$.
  - إذا كان العكس فإن الجذر في النصف الثاني $\implies a = c$.
- **شروط التوقف**: $|f(c)| < \text{tol}$ أو الخطأ المطلق $\frac{b - a}{2} < \text{tol}$.
- **رتبة التقارب**: خطية $\mathcal{O}(2^{-n})$؛ ومقدار الخطأ الأقصى في الدورة $n$ هو $\frac{b - a}{2^n}$.
- **الميزة الأساسية**: مضمونة التقارب دائماً طالما تم حصر الجذر داخل فترة سالبة/موجبة.

#### طريقة نيوتن-رافسون (Newton-Raphson Method)
- **الأساس النظري**: تعتمد على مفكوك تايلور من الدرجة الأولى $f(x) \approx f(x_n) + f'(x_n)(x - x_n)$. مد مماس المنحنى حتى يتقاطع مع محور السينات يعطي العلاقة:
  $$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$$
- **شروط التوقف**: $|f(x_{n+1})| < \text{tol}$ أو $|x_{n+1} - x_n| < \text{tol}$.
- **رتبة التقارب**: تربيعية $\mathcal{O}(h^2)$ عند الجذور البسيطة (يتضاعف عدد الأرقام العشرية الصحيحة تقريباً في كل دورة).
- **حالات الخطر**: تتوقف الدالة إذا انعدمت المشتقة $f'(x_n) \approx 0$ (مماس أفقي يستحيل معه القسمة).

#### طريقة القاطع الكلاسيكية (Secant Method)
- **الأساس النظري**: تتفادى الحاجة لحساب المشتقة تحليلياً بالتعويض عنها بميل المستقيم القاطع بين نقطتين سابقتين $x_{n-1}$ و $x_n$:
  $$x_{n+1} = x_n - f(x_n) \cdot \frac{x_n - x_{n-1}}{f(x_n) - f(x_{n-1})}$$
- **شروط التوقف**: $|f(x_{n+1})| < \text{tol}$ أو $|x_{n+1} - x_n| < \text{tol}$.
- **رتبة التقارب**: فوق خطية (Superlinear) بقوة النسبة الذهبية $\phi \approx 1.618$.

#### طريقة القاطع المعدلة (Modified Secant Method)
- **الأساس النظري**: بدلاً من اشتراط إدخال نقطتين منفصلتين، تستخدم الطريقة نقطة واحدة $x_i$ مع نسبة اضطراب جزئي صغيرة $\delta$ (الافتراضي $\delta = 0.01$):
  $$x_{i+1} = x_i - \frac{\delta \cdot x_i \cdot f(x_i)}{f(x_i + \delta \cdot x_i) - f(x_i)}$$
- **الميزة الحسابية**: تجمع بين سرعة طريقة القاطع وسهولة الإدخال بنقطة واحدة، مع معالجة خاصة للنقاط القريبة من الصفر بجعل مقدار الخطوة $h = \delta$.

### 2. طرق حل أنظمة المعادلات الخطية (Linear Systems)

تستخدم لحل الجمل الخطية من الشكل:
$$A\mathbf{x} = \mathbf{b}$$

#### طريقة جاكوبي للتكرار (Jacobi Method)
- **القانون**: يتم تفكيك المصفوفة $A = D + L + U$. يتم حساب كل عنصر في المتجه الجديد باستخدام قيم المتجه السابق حصراً:
  $$x_i^{(k+1)} = \frac{1}{a_{ii}} \left( b_i - \sum_{j \neq i} a_{ij} x_j^{(k)} \right)$$
- **الذاكرة**: تتطلب حفظ نسختين من المتجه (السابق والحالي).

#### طريقة جاوس-سيدل (Gauss-Seidel Method)
- **القانون**: بمجرد حساب القيمة الجديدة $x_j^{(k+1)}$ للمتغير السابق، يتم استخدامها فوراً في نفس الدورة لحساب المتغيرات اللاحقة:
  $$x_i^{(k+1)} = \frac{1}{a_{ii}} \left( b_i - \sum_{j < i} a_{ij} x_j^{(k+1)} - \sum_{j > i} a_{ij} x_j^{(k)} \right)$$
- **السرعة والذاكرة**: أسرع بنحو الضعف من جاكوبي، وتحدث القيم في نفس موضع الذاكرة (In-place).

#### شرط السيادة القطرية الصارمة (Diagonal Dominance)
الشرط الكافي الذي يضمن تقارب حلي جاكوبي وجاوس-سيدل لأي تخمين ابتدائي هو أن يكون العنصر القطري في كل صف أكبر بالقيمة المطلقة من مجموع باقي عناصر الصف:
$$|a_{ii}| > \sum_{j \neq i} |a_{ij}| \quad \forall i \in \{1, \dots, n\}$$
تم تزويد البرنامج بخوارزمية فحص وإعادة ترتيب تباديل الصفوف تلقائياً عبر الدالة [`make_diagonally_dominant(A, b)`](file:///home/myarch/Projects/math%203/math_utils.py) لتحقيق هذا الشرط قبل البدء بالحساب.

### 3. الانحدار ومواءمة المنحنيات (Curve Fitting & Regression)

إيجاد دالة تقريبية $y \approx f(x)$ تمثل مجموعة نقاط تجريبية $\{(x_i, y_i)\}_{i=1}^n$ بأقل مجموع لمربعات الأخطاء (Least Squares):
$$\min S_r = \sum_{i=1}^n (y_i - f(x_i))^2$$

#### الانحدار الخطي (Linear Regression)
يوافق مستقيماً بالمعادلة $y = a_0 + a_1 x$ عبر حل المعادلتين القياسيتين:
$$a_1 = \frac{n \sum x_i y_i - \sum x_i \sum y_i}{n \sum x_i^2 - (\sum x_i)^2}, \quad a_0 = \bar{y} - a_1 \bar{x}$$

#### انحدار متعدد الحدود (Polynomial Regression)
يوافق منحنى بالمعادلة $y = a_0 + a_1 x + a_2 x^2 + \dots + a_m x^m$ لأي درجة $m$ يحددها المستخدم. يتم إنشاء وحل نظام المعادلات القياسية المتماثل بحجم $(m+1) \times (m+1)$ باستخدام الحذف الغاوسي مع التبديل الجزئي للصفوف (Partial Pivoting).

#### المواءمة الأسية (Exponential Fitting)
توفيق دالة أسية $y = a \cdot e^{b x}$ عبر التحويل اللوغاريتمي الخطي $\ln(y) = \ln(a) + b x$ (يشترط أن تكون جميع $y_i > 0$).

#### مواءمة دالة القوى (Power Function Fitting)
توفيق دالة قوى $y = a \cdot x^b$ عبر التحويل اللوغاريتمي الخطي $\ln(y) = \ln(a) + b \ln(x)$ (يشترط $x_i > 0$ و $y_i > 0$).

#### المقاييس الإحصائية المعتمدة
- **مجموع مربعات الانحرافات الكلي**: $S_t = \sum (y_i - \bar{y})^2$
- **مجموع مربعات البواقي (SSE)**: $S_r = \sum (y_i - \hat{y}_i)^2$
- **معامل التحديد**: $R^2 = \frac{S_t - S_r}{S_t}$ (تتراوح قيمته بين 0 و 1 وكلما اقترب من 1 كانت المواءمة ممتازة).
- **الخطأ المعياري للتقدير**: $S_{y/x} = \sqrt{\frac{S_r}{n - (m + 1)}}$

```bash
sudo pacman -S tk python
```

> **ملاحظة لمستخدمي التوزيعات الأخرى:**
> - على **Ubuntu / Debian**: `sudo apt install python3 python3-pip python3-tk`
> - على **Fedora**: `sudo dnf install python3 python3-tkinter`

### 2. إنشاء وتفعيل البيئة الافتراضية (.venv)
داخل المجلد الرئيسي للمشروع:
```bash
# إنشاء بيئة افتراضية مستقلة
python -m venv .venv

# تفعيل البيئة على طرفية باش/زد-شيل
source .venv/bin/activate
```

### 3. تثبيت مكتبات بايثون المطلوبة
قم بتحديث مدير الحزم `pip` وتثبيت الاعتماديات:
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

2. **`python-bidi`**: تطبق خوارزمية الاتجاه الثنائي (Unicode BiDi) لقلب اتجاه السلسلة لتناسب العرض من اليمين إلى اليسار.
3. **الدالة المساعدة [`ar(text)`](file:///home/myarch/Projects/math%203/app.py)**: تمرر من خلالها كافة النصوص الثابتة، رسائل التنبيه، ترويسات الجداول ومسميات الرسوم البيانية.

## دليل حل المشاكل الشائعة (Troubleshooting)

### مشكلة عدم العثور على مكتبة Tkinter (`libtk8.6.so`)
- **السبب**: عدم تثبيت حزمة `tk` على مستوى نظام Arch Linux.
- **الحل**: نفذ الأمر `sudo pacman -S tk`.
- **ميزة إضافية**: تم تضمين فحص احتياطي داخل `app.py` يكتشف وجود ملفات المكتبة داخل مجلد `.venv/lib` وتمريرها تلقائياً للمتغير `LD_LIBRARY_PATH`.

### مشكلة اختيار المفسر غير الصحيح في بيئات التطوير (VS Code / Antigravity)
- **العَرَض**: ظهور رسالة خطأ `ModuleNotFoundError: No module named 'customtkinter'`.
- **السبب**: بيئة التطوير تحاول التشغيل باستخدام مفسر النظام العام `/bin/python` بدلاً من مفسر البيئة الافتراضية `.venv`.
- **الحل**:
  1. تم تضمين الإعداد تلقائياً في `.vscode/settings.json`:
     ```json
     {
       "python.defaultInterpreterPath": "${workspaceFolder}/.venv/bin/python"
     }
     ```
  2. يمكنك الضغط على `Ctrl + Shift + P` ثم كتابة `Python: Select Interpreter` واختيار `.venv/bin/python`.

### مشكلة مقياس الشاشة على خوادم العرض الحديثة (Wayland / Hyprland)
- **العَرَض**: ظهور عناصر الواجهة بحجم أصغر أو أكبر من اللازم على شاشات الدقة العالية (HiDPI / 2K / 4K).
- **الحل**: يتيح البرنامج التحكم اليدوي بنسبة التكبير عبر متغير البيئة `CTK_SCALING`:
  ```bash
  # لتشغيل البرنامج بمقياس 100% عادي:
  CTK_SCALING=1.0 ./.venv/bin/python app.py

  # لتشغيل البرنامج بمقياس تكبير 125%:
  CTK_SCALING=1.25 ./.venv/bin/python app.py
  ```
